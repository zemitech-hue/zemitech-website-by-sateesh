# Construction Division — Image Prompts & File List

This document lists all images needed for the **Construction Division** (4 Sub-services + Construction Overview + Construction Service Cards).

---

## 💡 Quick Rules
- **Format**: Save every file as **`.png`**.
- **Hero Images (`hero.png`)**: `--ar 16:9`. Keep the **left side simple/empty** (sky or plain wall) because text will overlay on the left. Put the main subject on the **right side**.
- **Card Images (`card-1.png`, etc.)**: `--ar 16:10`. Subject centered, filling frame.
- **Material Images (`material-1.png`, etc.)**: `--ar 1:1`. Close-up macro texture shot filling the square frame. No people or text.
